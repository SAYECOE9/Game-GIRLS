A sleek, modern, and dark-themed landing page template designed for gaming projects, character art showcases, and creative portfolio hubs. Features glassmorphism UI elements, smooth micro-interactions, custom typography, and a prominent hero layout.

---

## ✨ Features

- **Dark Radial Theme:** Aesthetic gradient background built with CSS radial gradients for a cinematic feel.
- **Glassmorphism UI:** Modern translucent controls and buttons utilizing CSS `backdrop-filter: blur()`.
- **Custom Typography:** Integrated Google Fonts (`Inter`, `Chakra Petch`, `Bruno Ace SC`).
- **Interactive Micro-Animations:**
  - Hover effects on navigation links with letter-spacing.
  - Rotating menu button with glowing shadow.
  - Interactive "Discover More" CTA button with slide-arrow effect.
  - Floating social media icons with smooth elevation.
- **Character Hero Showcase:** Dedicated absolute-positioned image frame for featured artwork/character renders.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic markup structure.
- **CSS3:** Custom styles, CSS gradients, CSS transitions, flexbox, and backdrop filters.
- **Font Awesome 6.5.2:** Vector icons for social links and navigation actions.
- **Google Fonts API:** Web fonts integration for modern gaming aesthetic.
